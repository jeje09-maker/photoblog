도움말 및 자주 묻는 질문 (FAQ)

네! photoBlog 웹 애플리케이션 자체는 무료로 이용 가능합니다. 본인의 Gemini API 키를 입력하여 사용하므로, 사용량에 따른 비용은 Google AI Studio의 약관을 따릅니다. 개인 한도 내에서 무료 티어를 적용받을 경우 사실상 요금이 발생하지 않거나 월 1만 원 내외의 극히 저렴한 금액으로 무제한 포스팅 빌드가 가능합니다.

다음 절차를 수행하세요:

  1. Google AI Studio 공식 웹사이트에 구글 계정으로 로그인합니다.
  2. 화면 좌측 상단의 [Get API key] 버튼을 누릅니다.
  3. [Create API Key]를 클릭하고 프로젝트를 선택하여 발급된 키(`AIzaSy...`)를 복사합니다.

기사 넘기기 기능은 네이버의 글쓰기 편집창인 스마트에디터 ONE의 환경을 시뮬레이션하고, 생성된 텍스트와 이미지를 원클릭으로 주입하도록 돕는 자동화 가상 장치입니다. 실제 브라우저 자동 주입과 동일하게 에디터 곳곳에 소스가 채워지는 모습을 시각적으로 검증하고 그대로 옮겨갈 수 있도록 구현되었습니다.

AI가 글을 풍부하고 실감 나게 묘사할 수 있도록 3장~8장 정도의 업로드를 적극 권장합니다. 너무 많은 이미지는 토큰 사용량을 늘리며 비용을 상승시키거나 처리 속도를 늦출 수 있으므로 적절하게 핵심 사진을 압축해서 올려주시는 것이 좋습니다.

네이버의 DIA+나 C-Rank 알고리즘은 글의 독창성과 실제 정보를 면밀히 살핍니다. photoBlog는 기계식 복사글이 아닌 실제 업로드된 사진 속 고유 요소(색감, 그릇 배치, 풍경 디테일)를 비전 모델이 직접 읽고 서술하므로 검색 품질이 매우 높습니다. 다만, 최종 발행 전에 '본인만의 주관적인 짧은 경험담이나 의견'을 1~2줄 추가해주시면 검색 랭킹에 훨씬 더 높은 점수를 획득하실 수 있습니다.
